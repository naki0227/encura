# EnCura 復旧診断（2026-10-20）

App Store 公開版 1.04（2025-12-18 公開）が正常に動かなくなっている原因の一覧です。
オーナー作業の手順は [RELEASE.md](RELEASE.md) にあります。

あわせて、出典のない記事を入れるだけだった一回限りのスクリプト 2 本（`seed_trends.py` と、会期が 2025 年 1 月に終わった展覧会の記事を入れるもの）を削除しました。
既に DB に入っている過去の記事・展覧会は、出典が確認されていないものを含みます。展覧会は終了日を過ぎると表示されなくなります。トレンド記事は残るので、気になる場合は `source_url` が空の記事を非公開（`is_published = false`）にしてください。

## 2026-10-25 の方針変更

- **Supabase**: 旧プロジェクトは復元できなかったため、会社のアカウントで新しく作る。旧 DB の中身は引き継がない（自動生成の記事で、出典のないものが多かった）。
- **スキーマ**: 手で流していた `supabase/*.sql`（重複・矛盾あり、展覧会テーブルに RLS がなく誰でも書き換えられる状態だった）をやめ、`supabase/migrations/20261025000000_baseline.sql` 1 本にまとめた。全テーブルで RLS を有効にし、利用者が書けるのは匿名サインイン済みの館内マップ投稿だけにした。
- **コンテンツ**: GitHub Actions + Gemini のクローラーをやめ、毎日の Claude の定期実行が集めて確かめたものを、日時入りのマイグレーション（`<UTC日時>_content_<日付>.sql`）として PR にする。CI がローカルの Supabase で試し、中身が「コンテンツの追加だけ」なら自動でマージして本番に当てる。適用済みの版は `supabase_migrations.schema_migrations` に記録される。手順は [CONTENT_ROUTINE.md](CONTENT_ROUTINE.md)。
- **Gemini**: アプリ内のチャット・作品スキャン・マップ判定だけで使う（記事集めでは使わない）。点検もモデル一覧を見るだけにして、料金がかからないようにした。
- **画像最適化（2026-10-26）**: Cloud Run の Rust サービスがしていたのは「幅 1024px に縮小して JPEG 品質 80 で保存し直す」ことだけだった。これを撮影時にアプリの中で行うようにし、サービス・CI のビルド・点検をなくした（#5 の再デプロイは不要になった）。Cloud Run のサービスはオーナーが削除する（RELEASE.md 手順 3）。
- **確認したこと**: ローカルの Supabase（DB・API・認証・ストレージ）で、マイグレーションの適用と `supabase db push` での版の記録、RLS（匿名では書けない／匿名サインイン済みはマップ投稿だけできる／削除はできない）、ストレージへの投稿、アプリの表示と地図ボタンを確かめた。
- **このとき見つかった不具合（#27）**: ホームから開いた展覧会で会場 ID を読み込んでおらず、会場に投稿されたマップが出ず、展覧会の画面から投稿したマップも会場に結び付かなかった。読み込むように直した。

## 埋め込みキーの確認

- 修正後のアプリには、Gemini のキーも `.env` も入りません。アプリが持つのは Supabase の URL と anon キー（公開前提のキーで、RLS で守る）と最適化サービスの URL だけで、どれもビルド時に `--dart-define` で渡します。
- リポジトリと履歴（取得した範囲）に `AIza…` 形式のキーはありません。`.env` がコミットされた形跡もありません。
- 公開中の 1.04 のバイナリには無効化済みのキーが入っています。キーは無効なので悪用はできませんが、1.0.5 の公開後は 1.04 を配信し続ける理由はありません。

## そのままにしたもの（今回の範囲外）

- `flutter_markdown` は提供終了（後継は `flutter_markdown_plus`）。今のところビルド・動作に問題はありません。
- `venue_maps` テーブルと Storage は匿名でも INSERT できるポリシーのまま（以前からの設計）。
- Python クローラーは提供終了した `google-generativeai` SDK をやめ、Gemini の REST API を直接呼ぶ形にしました（SDK の改名・終了に左右されないため）。
